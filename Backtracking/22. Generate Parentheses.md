# [22. Generate Parentheses](https://leetcode.com/problems/generate-parentheses/)

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        generateParenthesis(result, "", n, 0, 0);
        return result;
    }

    private void generateParenthesis(List<String> result, String cur, int n, int open, int close) {
        if (close == n) {
            result.add(cur);
            return;
        }
        if (open < n) {
            generateParenthesis(result, cur + "(", n, open + 1, close);
        }
        if (close < open) {
            generateParenthesis(result, cur + ")", n, open, close + 1);
        }
    }
}
```
